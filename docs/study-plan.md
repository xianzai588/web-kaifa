# 学习计划

学习网站按“入门 → 初阶 → 中级 → 高级”组织125个系统教程章节，完整顺序见 [教学大纲](teaching-outline.md)。先学具体概念，再做有注释的小例子与阶段项目；网页语言、浏览器与服务器、HTML 模板与 API、前后端框架的衔接单独解释。方向内的目录放在左栏，按阶段分页，正文一次只展示一章。原教材的天数只是项目练习安排，不能替代零基础的知识顺序；当前没有把任何学习任务标记为完成。

读完一个知识点，先完成紧随讲解的“就地练习”，写下预测、实际结果与原因，再展开“参考核对”。这些小题不要求切到练习工坊；章末独立任务用于组合知识。代码块和预期输出均可复制，复制后仍需自己保存、运行并验收。

## Web：先打基础，再选择路线

| 层级 | 学习范围 | 要留下的成果 |
| --- | --- | --- |
| 入门 | 浏览器与三种网页语言的分工；HTML结构、标签、文字、链接、图片、表单；CSS规则、选择器、单位与盒模型 | 从空文件独立写学习名片 |
| 初阶 | 文档流、Flex、Grid、媒体查询、定位、溢出与键盘状态 | 响应式活动页，多宽度与键盘结果 |
| 中级 | JavaScript变量、分支、循环、函数、数组、对象，再学DOM、事件、模块、JSON和请求 | 活动筛选与加载、空结果、失败状态 |
| 高级 | npm、组件与框架的职责、TypeScript、生命周期、测试、性能、构建发布与Go联调 | 可以按README重现的前端或全栈项目 |

系统正文在 [Web课程目录](courses/web)，网站“Web开发”按顺序阅读。原14课任务见 [Web教材](../materials/web/学习路线.md)，对应记录在 [Web进度](../progress/web.md)。React与Vue第一遍选一条；当前完整工程主例采用React，Vue提供基础比较入口。

网站后续12阶段有 [补充完整讲义](followups) 与 `exercises/web/followup-00..11` 独立配套。先按共同基础00–02走，再选前端03–06或全栈07–11；每个项目按 README 配置环境、运行和验证，不把清单当作已完成课程。第00阶段同时教素材绘制、SVG/PNG、裁切与导出。

## Go：先学语言，再实现后端

| 层级 | 重点 | 验收目标 |
| --- | --- | --- |
| 入门 | 编辑运行、程序结构、注释、变量、类型、常量、运算、条件、数字/整行输入与格式化输出、循环、函数与作用域 | 能解释并独立重写学习时长计算器 |
| 初阶 | 数组、切片、map、Unicode、指针、结构体、方法、接口、错误、包、测试、JSON、输入与文件 | 词频计数与稳定排名，正常和空输入验收 |
| 中级 | 浏览器/服务器、URL、HTTP请求与响应、Handler、输入校验、框架职责、HTML模板、CRUD、SQL、参数绑定、事务、Repository、配置、分页与共享数据保护 | 实际请求正确，持久化与失败边界有证据 |
| 高级 | channel、context、类型断言、泛型、密码、会话、授权、退出、容器、CI、剖析与恢复 | 两用户隔离、取消与恢复实验，可复现交付 |

系统正文在 [Go课程目录](courses/go)，网站“Go后端”按层级阅读，不需要C++前置。原28课保留为项目练习，见 [Go教材](../materials/go/完整学习清单.md) 与 [Go进度](../progress/go.md)。[刷题记录API](../projects/go/problem-tracker/README.md)仍是待实现计划；可运行参考使用本仓库实际提供的活动API、数据库与会话项目。

环境起步先看 [Go环境](tutorials/go-environment.md) 与 [VS Code](tutorials/vscode.md) 的打开文件夹、保存和终端操作。能运行一句打印后开始语法。学过变量与函数后，才选读第8–13节的工具配置和断点；[问候练习](../exercises/go/vscode-first-program/README.md)是独立调试参考。cmd与PowerShell使用各自的启动写法。

## 两条路线如何衔接

先完成一小段学习闭环，例如一个 Web 页面或 Go 第一个 HTTP 接口，再切换方向。网页先学 HTML、CSS、JavaScript；API 交互先认识浏览器、服务器和 HTTP，再学习请求代码。Go 能返回 JSON，也能用 HTML 模板生成页面，这两种方式有独立章节和例子。

组件与框架在原生页面交互之后学习：先遇到多处 DOM 随数据同步的问题，再认识 React/Vue 怎样组织组件。后端框架在 Handler 与请求测试之后比较，说明标准库、中间件和框架各自做什么。其他语言的后端放在选学对照中，不作为写 HTML 或开始 Go 的前置条件。

全栈教材中的后端内容可以作为概念参考。使用 Go 实现时，以 Go 教材和自己项目的 API 契约为准，不必同时实现多套后端技术栈。

每天留存三样东西：自己写的代码、实际运行或测试的结果、当天仍不理解的问题。复盘模板见 [每日笔记](../templates/daily-note.md)。

## 需要补练时，从一个小任务开始

网站的“知识地图”按基础、应用、综合组织 24 个主题，“练习工坊”提供 18 个任务。这些是教材的补充，不把参考例子运行成功当作学习完成。已有编程基础者可以先做独立任务，遇到边界再回看概念；零基础者先按课时，再用起步提示完成最小步骤。

| 当前学习段 | 建议补练 | 要留下的结果 |
| --- | --- | --- |
| Web 入门 | 语义介绍页、盒模型测量 | 自己的代码、尺寸预测与实测、结构解释 |
| Web 初阶 | Flex/Grid 布局、长内容与手机页面 | 多视口截图、键盘焦点与没有横向溢出的页面 |
| Web 中级 | 纯函数筛选、活动搜索、请求状态 | 正常与空输入、加载/成功/空/失败结果 |
| Web 高级 | 组件复用、类型边界、前后端联调 | 构建结果、组件测试和真实请求的证据 |
| Go 入门 | 分数统计、学习时长计算器 | 能预测输出并从空文件独立写一个变式 |
| Go 初阶 | 词频、结构体、JSON 与文件 | 真实输入输出、表驱动测试和错误输入结果 |
| Go 中级 | HTTP、HTML模板、CRUD 契约、数据库约束 | 请求与响应、真实测试库结果、失败事务回滚 |
| Go 高级 | 两用户隔离、取消与退出 | 拒绝跨用户操作、取消信号结果、复现说明 |

四套实际可运行的参考起点：[活动搜索](../exercises/web/activity-filter/README.md)、[请求状态](../exercises/web/request-states/README.md)、[词频统计](../exercises/go/wordfreq/README.md)、[HTTP 基础](../exercises/go/http-basics/README.md)。其他工坊任务写明需要已有项目或数据库的条件，不是已经实现的项目功能。
