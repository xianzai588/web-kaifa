# 标签、元素与属性

看懂开始标签、结束标签、内容和属性。

## 把一行代码拆成四个部分

看 `<p id="intro">文字</p>`：`<p ...>` 是开始标签，`文字` 是内容，`</p>` 是结束标签，三者组成一个 `p` 元素。`id="intro"` 是属性；`id` 是属性名，`intro` 是属性值。属性写在开始标签中，用英文引号包住值。

**标签名称告诉浏览器“内容是什么”，属性补充“这个元素有哪些信息”。** `strong` 表达这段文字的重要性，浏览器通常以粗体显示。它嵌套在 `p` 中，结束时先关闭里面的 `strong`，再关闭外面的 `p`。

HTML 注释写成 `<!-- 给读代码的人看的说明 -->`。注释会留在源码中，通常不显示成正文；这里用它标明强调的范围。HTML 不使用 JavaScript 的 `//` 作为注释。

本节预期段落显示“我在学HTML。”，其中只有“HTML”被强调。没有结束标签的元素叫空元素，例如后面会学的 `img`、`input`；不能据此省略普通段落的结束标签。

### 就地练习：圈出强调范围

独立写一句“先保存，再刷新”，只强调“保存”，为整个段落取唯一id。指出属性属于哪个开始标签。

### 参考核对：圈出强调范围

strong只包保存，id写在p开始标签；先关strong再关p，id文字不显示成正文。

## 空元素、布尔属性与字符引用

img、input、br、meta 等是空元素，不写结束标签；div、p、strong 等需要正确闭合。属性写在开始标签中，id 在同一文档应唯一。required 这类布尔属性只要出现就表示启用，`required="false"` 也不会把它关闭。

要显示小于号或 &，可用 `&lt;`、`&amp;`，引号属性里可用 `&quot;`。HTML 注释写成 `<!-- 说明 -->`；注释会随源码发送给读者，不能用来藏密码或隐私。strong 表达重要性，em 表达语气强调，外观可以另由 CSS 调整。

### 就地练习：布尔属性不是真假字符串

给练习input写required="false"，尝试空值提交；随后删除required再比较。

### 参考核对：布尔属性不是真假字符串

只要属性存在即启用必填，false文字不会关闭；删除属性才关闭该原生要求。

## 先看一个完整例子

在自己的独立练习文件夹新建 index.html，保存下面完整内容，用浏览器打开。修改后先保存，再刷新。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>本节小练习</title>
</head>
<body>
<!-- id 标识整个段落；strong 只强调它包住的 HTML 这四个字母。 -->
<p id="intro">我在学<strong>HTML</strong>。</p>
</body>
</html>
```

## 逐步读懂这个例子

p包住整个段落。strong包住HTML这段文字，表达强调。id="intro"给段落一个标识，本节先知道它的位置，链接章节再使用。属性的值放在英文引号内。

## 自己改一处再观察

把strong移到“我在学”外面，观察强调范围。

### 参考答案

strong 包住的范围才被表达为重要内容，移走开始与结束标签必须一起检查嵌套。

## 嵌套错误为何不一定马上显眼

浏览器会尝试纠正错位标签，因此屏幕文字可能仍可读。检查 Elements 中 strong 实际包住哪段内容，再回源文件修复闭合顺序；不要用额外结束标签反复补到“看起来对”。

### 就地练习：看源码也看DOM

把临时页面的strong和p结束顺序故意错位，在Elements查看浏览器修复结果，再恢复合法嵌套。

### 参考核对：看源码也看DOM

浏览器可能重排标签，屏幕仍有文字；应使源码与想表达的嵌套一致，不靠再补结束标签碰运气。

## 独立变式：只强调通知中的截止时间

**先合上原例，再从空白文件完成下面的目标。** 可以查本节概念和已经学过的章节，先写自己的预期；不要复制参考程序再换几个字。使用 p、strong、id 和正确的嵌套；不加入还没学的样式。

在空文件写一条完整通知：“请在周五下午前交作品，文件名写清姓名。”只强调“周五下午”，给整段一个自己的唯一 id，并留一条说明强调范围的 HTML 注释。

自查：正文整句仍可读，只有截止时间被强调，属性值和注释不当成正文显示。源码先关闭 strong 再关闭 p；若把结束顺序打乱，不能因为浏览器看似显示了内容就判为正确。

### 参考答案：独立变式

先关闭 strong 再关闭 p，id 给整段命名，不会成为正文文字。注释解释强调原因，浏览器正文不显示注释。

下面是完整 index.html，保存后用浏览器打开；需要服务器时按本节启动说明运行。

```html
<!doctype html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>独立练习</title>
</head>
<body>
<!-- 截止时间决定提交安排，因此只强调这个范围。 -->
<p id="submission-note">请在<strong>周五下午</strong>前交作品，文件名写清姓名。</p>
</body>
</html>
```
