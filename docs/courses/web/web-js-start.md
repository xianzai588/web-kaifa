# JavaScript 的运行位置

区分HTML结构与script中的执行语句，查看控制台。

## 第一次读执行语句

**JavaScript 可以在计算机上执行操作；HTML 标签本身不执行这些计算。** 浏览器读到本例的 script 时，从上往下执行其中两条语句。

`console` 是浏览器提供的控制台对象，点号后 `log` 是它的一个方法；`console.log(...)` 中的括号表示调用，括号内是交给它输出的值。`"第一行"` 是字符串，英文引号不是要显示的内容；`2+3` 是计算表达式，先得到数字 5 再输出。分号标明语句结束。

JavaScript 单行注释写 `// 说明`，多行注释写 `/* 说明 */`。下面注释解释每条语句的目的，浏览器不会把注释执行成操作。

保存 index.html 并打开，按 F12 或从浏览器菜单进入“开发者工具”，选择 Console（控制台），再刷新页面。应按顺序出现“第一行”和“5”；正文仍是原来的 h1 与 p。若有红色错误，先核对英文引号、括号、文件是否保存。控制台现场输入的临时代码不会自动保存到文件。

### 就地练习：结果出现在哪

在完整HTML脚本中输出2*6，预测Console与body各自变化，再刷新核对。

### 参考核对：结果出现在哪

Console显示12，body不会自动显示12；console.log不修改正文。

## 脚本何时执行，错误在哪里出现

页面内 script 到达时会执行其中的语句；外部脚本用 `<script src="main.js" defer></script>` 可以在 HTML 解析后执行，并保持文档顺序。不要把 JS 写成正文中的普通文字，也不要把 Console 中的一次临时执行当作文件已保存。

语法错误通常阻止对应脚本执行，运行时错误则可能发生在前面语句已执行之后。根据 Console 的文件名、行号与第一条原因定位，刷新前清理旧日志，确认看的是这次保存后的版本。alert/prompt 适合极小演示，会打断交互，正式页面用表单控件和 DOM 显示数据。

### 就地练习：两种错误的时机

在临时副本对比缺括号的语法错误与第一条日志之后调用不存在函数的运行时错误，每次只留一种。

### 参考核对：两种错误的时机

语法错误可能阻止对应脚本执行；运行时错误前的语句可能已执行。修复保存后重新刷新。

## 先看一个完整例子

在自己的独立练习文件夹新建 index.html，保存下面完整内容，用浏览器打开。修改后先保存，再刷新。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>本节小练习</title>
</head>
<body>
<h1>JavaScript 小实验</h1>
<p>按 F12 打开开发者工具，在 Console（控制台）看输出。</p>
<script>
// 输出文字到开发者工具的 Console，不是写入页面正文。
console.log("第一行");
// 先计算表达式 2 + 3，得到数字 5，再把结果交给 log。
console.log(2 + 3);
</script>
</body>
</html>
```

控制台预期：

```output
第一行
5
```

## 逐步读懂这个例子

script在本例body末尾，内容按顺序执行。带引号的是文字，不带引号的2+3是表达式，先算成5再输出。分号表示语句结束，本教程保持明确写法。

## 自己改一处再观察

将2+3改成2*3，保存并刷新；清楚区分正文与控制台。

### 参考答案

2+3 改成2*3，第二条控制台结果由5变6；正文仍由HTML决定，不会自动替换。

参考：[MDN Web 学习文档](https://developer.mozilla.org/zh-CN/docs/Learn_web_development)。

## 独立变式：只在控制台生成一张小收据

**先合上原例，再从空白文件完成下面的目标。** 可以查本节概念和已经学过的章节，先写自己的预期；不要复制参考程序再换几个字。本章仅使用 script、console.log、文字和算式；不要操作 DOM 或先使用变量。

独立创建页面与短脚本。正文介绍它是控制台练习；控制台先输出“本次采购”，再输出两份 6 元商品与 3 元运费合计的计算结果，最后输出“请自行核对”。先写下三行顺序和正文是否会改变。

自查：Console 依次出现主题、数字 15、收尾文字，正文没有自动变成收据。故意漏一个配对括号应得到语法错误，恢复保存/刷新后才重新正常。控制台临时输入不能替代保存文件。

### 参考答案：独立变式

三条同步日志按顺序执行，计算先乘后加。没有修改DOM的语句，正文保持不变。缺括号会导致语法错误，修复后保存刷新才重新输出。

下面是完整 index.html，保存后用浏览器打开；需要服务器时按本节启动说明运行。

```html
<!doctype html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>独立练习</title>
</head>
<body>
<h1>控制台独立练习</h1>
<p>打开开发者工具的 Console，核对下列日志。</p>
<script>
console.log("本次采购");
console.log(2 * 6 + 3);
console.log("请自行核对");
</script>
</body>
</html>
```
