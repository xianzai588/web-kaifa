# 网页、浏览器与三种基础语言

知道页面在哪里显示，分清 HTML、CSS、JavaScript 各负责什么。

## 先认识你正在操作的三个东西

**编辑器修改文件，浏览器读取文件；保存和刷新是两次不同的操作。** VS Code 是编辑器，Edge、Chrome 等是浏览器。文件夹用于把这个练习的文件放在一起；`index.html` 是文件名，最后的 `.html` 告诉工具它是一份 HTML 文档。确认它没有被保存成 `index.html.txt`。

HTML 是描述内容结构的标记语言；CSS 是描述外观的样式语言；JavaScript 是执行计算和操作的编程语言。先分清职责，不需要现在背三套语法。下面的 `<h1>` 和 `<p>` 分别包住主标题和段落；尖括号内是标记，标记之间是你想显示的文字。

用 VS Code“文件 → 打开文件夹”选择自己的练习目录；在左侧新建 `index.html`，复制示例，按 Ctrl+S（macOS 为 Command+S）保存。在文件管理器中双击这个文件，让浏览器显示它。地址栏是 `file:///.../index.html` 时，文件来自你本机磁盘，而不是网上的网站。

### 就地练习：保存和刷新分开

只在编辑器改主标题但暂不保存，刷新浏览器；再保存并刷新。记录什么时候才出现新内容，若自动保存已开启先关闭再试。

### 参考核对：保存和刷新分开

未保存时仍读取磁盘旧版，保存并刷新后才看到新标题；编辑器里的变化不等于浏览器已重新读取。

## 从一个文件开始

先在 `exercises/web` 下为自己新建一个练习文件夹，例如 `first-page`，再创建 `index.html`。用 VS Code 保存下面的完整内容，右键文件选择“在文件资源管理器中显示”，然后用浏览器打开。这里还不需要安装 Node 或任何框架。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <!-- 这个标题显示在浏览器标签页，不是正文大标题。 -->
<title>我的学习记录</title>
</head>
<body>
  <!-- body 内是浏览器要显示的页面内容。 -->
<h1>今天的学习记录</h1>
  <p>先把内容写清楚，再学习样式和交互。</p>
</body>
</html>
```

正文会出现一个标题和一段文字，浏览器标签页显示“我的学习记录”。下一节逐行解释这些标签，这一节先确认文件和显示结果的关系。

## 三种语言怎样分工

| 语言 | 在这张学习记录页中会负责什么 | 后面怎样学 |
| --- | --- | --- |
| HTML | 标题、文字、图片、链接、表单等内容的结构 | 先认识标签和属性，写一张完整页面 |
| CSS | 字体、颜色、间距以及手机和电脑上的布局 | 在 HTML 基础之后逐项改样式 |
| JavaScript | 点击后新增记录、筛选列表、向服务器请求数据 | 学完语言基本语法，再学习 DOM 和事件 |

HTML 中写一个按钮，只会得到一个按钮元素；点击后改变数据的行为需要程序。CSS 可以控制按钮的外观和部分交互样式，但不会替你保存学习记录。

本节的文件只有 HTML，所以页面能显示内容，还没有程序驱动的交互。浏览器已经为标题和段落提供了默认样式，因此“没有写 CSS”也不等于“所有文字必须一样大”。

### 就地练习：给需求找职责

把“介绍文字、卡片间距、点击后计数增加”分别分给HTML、CSS、JavaScript，只写分工暂不实现。

### 参考核对：给需求找职责

HTML组织文字，CSS调整间距，浏览器JS处理点击与数据变化；单有button标签不会保存记录。

## 浏览器与服务器分别在哪里

现在地址栏开头是 `file:`，浏览器直接读取你磁盘上的文件。发布网站后，浏览器通过 HTTP 从服务器取得 HTML，再取得页面引用的 CSS 和 JavaScript。

浏览器仍然负责显示页面。服务器可以直接发送保存好的 HTML，也可以运行 Go，把数据库中的记录填入 HTML 后发送给浏览器；还可以只返回 JSON 数据，由网页中的 JavaScript 更新页面。JSON 是以文字表示数据的一种格式，后面会单独学习。Go 程序运行的位置和浏览器中的 JavaScript 不同。

因此起步时先掌握 HTML、CSS、JavaScript。后面选择 Go、Node.js 或 Python，是在选择服务器上的开发方式。Node.js 是让 JavaScript 在浏览器以外运行的环境，不是另一门网页标记语言；不需要先把这些语言与工具都学一遍才能写网页。

### 就地练习：Go代码在哪运行

画出Go模板与JS请求JSON两种路线，分别标明谁生成初始HTML、谁更新页面。

### 参考核对：Go代码在哪运行

模板由服务器Go填好HTML发给浏览器；JSON路线由浏览器JS取数据并改DOM，Go不在浏览器中执行。

## 自己改一处再观察

把 `h1` 中的“今天”改成“第一天”，保存并刷新浏览器。再只修改 `title`，观察标签页和正文分别发生什么变化。

### 参考答案

h1 改为“第一天”只改变正文，title 改为“课程练习”只改变标签页。独立分工可核对：

| 需求 | 负责者 | 位置与证据 |
| --- | --- | --- |
| 课程名称与简介 | HTML | index.html 的标题和段落，刷新后可读 |
| 窄屏正文间距 | CSS | 样式规则，切换视口后检查计算样式 |
| 点击后次数变化 | 浏览器 JavaScript | 事件触发并更新 DOM，刷新是否保留由存储设计决定 |
| 跨电脑同一记录 | 服务器与持久化存储 | 需要身份、请求和保存服务；单个本机 HTML 做不到 |

编辑器保存源码，浏览器读取并显示。若改动没出现，先确认文件、保存与刷新，再查缓存和资源路径，不把“HTML能显示”当作全部功能已实现。

## 从输入地址到看到页面

浏览器读取 HTML，按它找到 CSS、图片与脚本，建立文档结构并布局绘制。CSS 或脚本路径错了，HTML 仍可能出现，但样式或交互缺失；打开开发者工具的 Network 和 Console 可以区分资源没找到、语法报错与界面规则不符合预期。

本机 file 地址从磁盘读取；http/https 地址通过请求取得资源。服务器可以返回静态 HTML，也可由 Go 模板生成 HTML；浏览器最终处理的仍是收到的文档。保存到 localStorage 的记录属于当前浏览器来源，不能自动在另一台电脑共享。

### 就地练习：页面出现但没样式

故意将自己的外部CSS地址写错，查看Network与正文。页面仍可读能否证明全部资源加载成功？

### 参考核对：页面出现但没样式

不能；HTML成功而CSS失败可同时发生，应检查单项资源状态和完整请求地址，恢复路径后再看样式。
