# 层叠、优先级与继承

判断同一属性最终使用哪一条规则。

## 用同一个属性追踪最终结果

**先看规则是否直接给当前元素赋值，再判断直接规则之间谁胜出。** 本例 div 是 p 的父元素，div 的绿色可以被后代继承；但 p 有直接声明时，不使用这份继承颜色。

在本例这种同一来源、未分层且没有 important 的普通规则中：ID 选择器的优先级高于类选择器，类高于标签；优先级相同才看谁写在后面。浏览器层叠还包括来源、重要性和层等条件，这个判断不是“任何时候看最后一行”。

按顺序预测并观察：三条都在时红色；删掉 `.note` 时蓝色；再删掉 `p` 时才继承绿色。`color`、文字字体等通常继承，`margin`、`border` 等通常不继承。

按 F12 打开开发者工具，选择 Elements（元素）面板，点选这个 p，再看 Styles（样式）中哪些 color 被划掉；Computed（计算值）显示最后颜色。工具只用于观察：在面板中改规则是临时修改，要保存仍得回编辑器改文件。

### 就地练习：先直接命中再看继承

父容器用ID设红色，子p用标签规则设蓝色，均为普通规则。预测子色并在Computed核对。

### 参考核对：先直接命中再看继承

子直接规则蓝色生效；不能拿父ID权重压过子元素直接声明，继承是另一条来源。

## 先看层叠来源，再比权重

“类比标签重”只适用于当前教学条件。完整层叠还区分来源、重要性、层叠层等，之后才比较选择器权重与书写顺序。普通直接命中颜色会覆盖从父元素继承的颜色，不能把父选择器权重直接搬到子元素与其直接规则竞争。

inherit 显式继承，initial 使用属性初始值，unset 对可继承属性等同继承、其他属性等同初始值。优先用短且可解释的选择器；看到覆盖冲突先看 Computed 和 Styles，别逐处加 !important 抬高维护成本。

### 就地练习：同权重才看先后

给同一段落写两条同类选择器颜色规则，交换次序；再将其中一条改为ID选择器观察。

### 参考核对：同权重才看先后

相同层叠条件和权重时后写胜出；ID权重更高时不只看代码末行。

## 先看一个完整例子

在自己的独立练习文件夹新建 index.html，保存下面完整内容，用浏览器打开。修改后先保存，再刷新。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>本节小练习</title>
  <style>
/* 父元素的颜色可供后代继承，但不会覆盖子元素直接指定的颜色。 */
div { color: green; }
/* 直接匹配段落，先于继承值参与选择。 */
p { color: blue; }
/* 同样直接匹配段落；本例中类选择器优先级高于标签。 */
.note { color: red; }
  </style>
</head>
<body>
<div><p class="note">观察我的颜色。</p></div>
</body>
</html>
```

## 逐步读懂这个例子

最终段落为红色。.note直接匹配段落，权重比标签p高；div提供的绿色只在子元素没有直接指定color时通过继承发挥作用。先判断是否直接指定，再比较规则。

## 自己改一处再观察

删除.note规则再观察；再删除p规则。

### 参考答案

移除 .note 后 p 的蓝色直接规则生效；再移除 p 的颜色规则，才使用父 div 的绿色。后写规则只有在其他层叠条件相同、权重相同时才凭次序胜出。

参考：[MDN Web 学习文档](https://developer.mozilla.org/zh-CN/docs/Learn_web_development)。

## 独立变式：预测两种覆盖来源

**先合上原例，再从空白文件完成下面的目标。** 可以查本节概念和已经学过的章节，先写自己的预期；不要复制参考程序再换几个字。只使用普通同来源、未分层、无 important 的规则，沿用当前优先级与继承范围。

独立写一个父容器与两个段落。父容器给文字一种颜色；第一段没有直接颜色，应继承。第二段给两条同为类选择器的直接颜色规则，使后出现的一条胜出。先记录自己的两段预期，再写代码。

自查：第一段按父色显示；第二段采用后出现的同权重类规则。交换两条类规则顺序只应改变第二段。移除第二段全部直接颜色后才回到继承色；用 Styles 的匹配/划线与 Computed 的最终色解释原因。

### 参考答案：独立变式

第一段无直接颜色，继承 green。第二段两条同权重规则，后写 purple 胜出；交换两条规则只让第二段变蓝，删去两条才继承绿色。

下面是完整 index.html，保存后用浏览器打开；需要服务器时按本节启动说明运行。

```html
<!doctype html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>独立练习</title>
<style>
.parent { color: green; }
.direct { color: blue; }
.direct { color: purple; }
</style>
</head>
<body>
<div class="parent">
  <p>我继承父色。</p>
  <p class="direct">我采用后写的类规则。</p>
</div>
</body>
</html>
```
