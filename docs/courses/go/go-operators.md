# 算术与比较运算符

计算总数、余数和比较结果，观察整数除法。

## 表达式先产生一个值

`7 / 2`、`score >= 60` 叫表达式，计算后各产生一个结果。算术得到数字，比较得到布尔值。**赋值 `=` 保存结果；比较 `==` 判断是否相等，二者不能交换。**

| 类别 | 写法 | 示例及结果 |
| --- | --- | --- |
| 加、减、乘、除 | `+`、`-`、`*`、`/` | `3 * 4` 为 12 |
| 整数余数 | `%` | `8 % 3` 为 2 |
| 相等、不等 | `==`、`!=` | `3 != 4` 为 true |
| 大小比较 | `>`、`>=`、`<`、`<=` | `60 >= 60` 为 true |
| 两个条件都成立 | `&&` | `true && false` 为 false |
| 至少一个条件成立 | `||` | `true || false` 为 true |
| 取反 | `!` | `!true` 为 false |

逻辑运算的两边必须是布尔值，例如 `(score >= 0) && (score <= 100)` 判断分数是否在范围内。`&&` 左边已为 false 或 `||` 左边已为 true 时，右边就不必再计算，称为短路。先用简单条件，下一课开始实际控制分支。

## 优先级、复合赋值与位操作

Go 的二元运算优先级从高到低是：`* / % << >> & &^`，`+ - | ^`，比较运算，`&&`，`||`。同级通常按从左到右组合，初学时用括号表达意图。例如 `2+3*4` 是 14，`(2+3)*4` 是 20。

`n += 2` 等价于本课的 `n = n + 2`。`n++`、`n--` 是单独的语句，不能写 `x = n++`，也没有 `++n`。逻辑运算不把整数 0 当作 false，`!1` 不合法。

位运算针对整数的二进制位：`&` 逐位与、`|` 逐位或、`^` 双操作数时逐位异或，单操作数时取反；`&^` 清除右侧为 1 的位。`<<` 左移，`>>` 右移。下面放 main 中观察，先认识即可，不作为分装题前置：

```go
fmt.Println(6 & 3, 6 | 3, 6 ^ 3, 6 &^ 3) // 2 7 5 4
fmt.Println(1 << 3) // 8
```

6 的二进制是 110，3 是 011。按位与得到 010，即 2；按位或得到 111，即 7。逻辑 `&&` 连接布尔条件，位 `&` 处理整数，二者解决不同问题。

### 参考核对：把优先级变成数字

结果为14、20、2、7；括号改变组合，按位运算按110和011逐位计算。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	fmt.Println(7 / 2)       // 整数相除，去掉小数部分，得到 3。
	fmt.Println(7 % 2)       // 7 = 3×2 + 1，余数是 1。
	fmt.Println(7.0 / 2.0)   // 本行使用带小数点的数，结果为 3.5。
	fmt.Println((2 + 3) * 4) // 括号里的加法先执行，再乘 4。
	fmt.Println(60 >= 60)    // 等于也满足 >=，因此是 true。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
3
1
3.5
20
true
```

## 逐步读懂这个例子

7/2 的两项都是整数，因此得到整数 3。7%2 的余数是 1。7.0/2.0 是小数运算，结果为 3.5。括号先把 2+3 算成 5，再乘 4。最后的比较结果为 true。

整数除法去掉小数部分，是向 0 截断；例如 `-7 / 2` 为 -3，不是 -4。带小数点的本例得到 3.5。加减与乘除混用时，乘除先做；括号能明确改变先后，所以 `(2+3)*4` 与 `2+3*4` 分别是 20 和 14。

如果以后 total 和 count 都是 int 变量，`float64(total) / float64(count)` 会先把两者明确转换为小数类型，再相除。**先做整数除法，再转换结果，已经丢失的小数不会回来。**

## 比较正常、边界与失败输入

把打印表达式依次换成 `8/3`、`8%3`、`(8+1)/3`，应得到 2、2、3；再分别打印 `60==60`、`60!=60`、`true && false`，应得到 true、false、false。

不要用 0 做本节整数除法或取余的右侧数字。直接写 `7/0` 会被编译器拒绝；若**整数**除数来自运行中的变量且为 0，会在运行时异常终止。

浮点变量不能直接套用这个结论：float64 变量除以零可以产生 `+Inf`、`-Inf` 或 `NaN`，分别表示无穷或不是一个有效数值，而不一定让程序异常退出。直接写常量表达式 `1.0/0.0` 则仍会被编译器拒绝。本节先使用有限的普通数和非零除数；处理浮点边界时要另行检查这些结果。

## 合上参考，独立计算分装结果

从空白 main.go 表示“17 本书，每箱最多放 4 本”，用两个整数变量保存输入。自行选择运算，依次输出能装满的箱数、剩下的本数、是否还有剩余；不要写尚未学到的分支。

先手算，再保存运行，自查：

| 总本数 | 每箱本数 | 整箱数 | 剩余本数 | 有剩余吗 |
| --- | --- | --- | --- | --- |
| 17 | 4 | 4 | 1 | true |
| 16 | 4 | 4 | 0 | false |
| 0 | 4 | 0 | 0 | false |

**三个结果都要由输入计算，不能把手算答案直接写进打印语句。** 每箱本数本题只允许大于 0，不用整数零除来表达“装不了”。

### 参考答案

满箱数用整数商，余下本数用余数，再把余数与 0 比较。将 books 改成 16 时为 4、0、false；改成 0 时为 0、0、false。perBox 必须大于 0，这里不使用尚未学到的 if。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	books := 17
	perBox := 4
	fmt.Println(books / perBox)
	fmt.Println(books % perBox)
	fmt.Println(books % perBox != 0)
}
```

预期结果：

```output
4
1
true
```
