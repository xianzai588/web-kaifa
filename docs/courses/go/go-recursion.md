# 递归与停止条件

跟踪函数调用自己，确认输入逐步靠近停止条件。

## 先认识一个可以拆小的问题

阶乘表示从正整数 n 一直乘到 1。例如 3 的阶乘写成 3!，结果是 3×2×1=6；0! 按定义为 1。于是 5! 可以拆成 5×4!，4! 再拆成 4×3!，直到小问题可以直接给出答案。

递归就是一个函数在自己的计算过程中再次调用自己。**递归必须有停止条件，也必须让每次调用的输入更接近停止条件。** 每次调用有自己的参数 n；这不是反复修改同一个全局 n。

先会 [函数调用和返回](../../../index.html#/learn/go/go-functions)、[if 条件](../../../index.html#/learn/go/go-if)。本节只用 0 到 10 的小整数，暂不解决负数或大数计算。

### 就地练习：画出三层等待

不运行，列出Factorial(3)向下调用的输入和向上返回的值。指出打印发生在返回前还是后。

### 参考核对：画出三层等待

向下3→2→1，向上1→2→6；main拿到6后才打印。每一层保留自己的n。

## 递归与循环怎样选择

计算 Sum(3) 时还要等待 Sum(2)，Sum(2) 等待 Sum(1)，每一层都保存自己的输入和返回位置；这需要额外调用空间。循环则在同一函数内反复更新累计值。对本课的一条数字序列，循环往往更简单；递归适合能自然拆成同类子问题的结构，例如后续可能遇到的树。

输入边界要在进入递归之前明确。当前 Sum 与 Factorial 只接受 0 到 10；负数不属于规则范围，大数也可能溢出。不能用“n 越来越小”作为全部证明：停止值必须可到达，例如每次减 2，却只在 n==0 停止，正奇数就会错过 0。

### 就地练习：缩小不一定到终点

假设只在n==0停止，每次递归n-2。分别跟踪起点4和3，不实际启动无限递归。

### 参考核对：缩小不一定到终点

4→2→0能停止；3→1→-1会错过0。必须证明输入在合法范围内且停止值可达。

## 完整 main.go

在已初始化的独立目录，替换 main.go，保存后运行：

```go
package main

import "fmt"

// Factorial 只在本课的小非负整数范围内计算阶乘。
func Factorial(n int) int {
	if n <= 1 {
		return 1 // 停止条件：0! 与 1! 都是 1，不再调用自己。
	}
	// 先取得较小问题的结果，再乘当前 n；每次 n 都减少 1。
	return n * Factorial(n-1)
}

func main() {
	fmt.Println(Factorial(5)) // 计算 5×4×3×2×1。
}
```

```sh
go run .
```

预期终端输出：

```output
120
```

## 先往下调用，再往上返回

Factorial(5) 还不能直接知道 4!，所以暂时等 Factorial(4) 的结果。接着按 5→4→3→2→1 调用，到 n=1 时直接 return 1，不再调用。

| 返回阶段 | 当前计算 | 返回给上一层 |
| --- | --- | --- |
| Factorial(1) | 直接返回 | 1 |
| Factorial(2) | 2×1 | 2 |
| Factorial(3) | 3×2 | 6 |
| Factorial(4) | 4×6 | 24 |
| Factorial(5) | 5×24 | 120 |

最终 main 得到 120 才打印。源码里的 return 可以包含另一次调用：先求出 `Factorial(n-1)`，再乘 n，最后返回当前结果。

## 预测停止与非法输入

| 输入 | 本节有效输入吗 | 预期 |
| --- | --- | --- |
| 0 | 是 | 1 |
| 1 | 是 | 1 |
| 3 | 是 | 6 |
| -1 | 否 | 现有函数会返回 1，这不是合法的负数阶乘 |

按前三个输入分别运行，记录结果。负数案例说明本函数依赖输入前提，不能把 `n<=1` 理解为已经校验所有整数。

若把 n-1 错写成 n，n=5 永远不会接近停止条件；若去掉停止分支，也会继续调用直到程序无法继续。先在纸上指出错误，不必故意让程序耗尽调用空间。int 的范围有限，大阶乘还可能溢出，当前程序不是任意精度工具。

## 独立写一个更小的递归

写 Sum(n int) int，计算 1 到 n 的和：n=0 时返回 0，其他有效输入返回 n 加上 Sum(n-1)。先手算 Sum(3)=6、Sum(0)=0，再运行；输入同样只允许本课的小非负整数。

### 参考答案

Sum(3) 等待 3 + Sum(2)，再等待 2 + Sum(1)，最后 Sum(0) 返回 0；向上依次得到 1、3、6。输入 0 直接返回 0，不再调用自己。这个版本不接受负数，调用者必须遵守题设，不能拿它当任意整数求和器。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

// Sum 的约定：输入为 0..10 的整数。
func Sum(n int) int {
    if n == 0 {
        return 0
    }
    return n + Sum(n-1)
}

func main() {
	fmt.Println(Sum(3))
	fmt.Println(Sum(0))
}
```

预期结果：

```output
6
0
```
