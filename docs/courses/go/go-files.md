# 文件读取与路径

读取一个本地文件，不存在时显示错误。

## 先认清目录、路径和内容

文件名是一个名字，例如 message.txt；路径描述从哪里找到它。当前工作目录是终端现在所在的文件夹。**相对路径由运行命令时的终端目录决定，不由你正在看的编辑器标签页决定。**

本节把 `main.go`、`go.mod`、`message.txt` 放在同一个独立练习文件夹。VS Code 新建文本文件时检查完整文件名，不要保存成 message.txt.txt；内容使用 UTF-8 保存。

ReadFile 一次把文件的全部字节读入内存，成功后我们转换成字符串显示。它负责打开与关闭文件，不需要手工 defer Close；后续若改用 os.Open 分段读取，才需要处理关闭。

### 就地练习：空文件与缺文件

在自己的临时练习目录分别准备空message.txt与不存在的missing.txt，预测ReadFile的err与数据长度。

### 参考核对：空文件与缺文件

空文件成功、err为nil、长度0；缺文件err非nil，不能再按空文件成功路径处理。

## 写入、追加、目录和权限

读取之外，最小写入可用 `os.WriteFile("notes-output.txt", []byte("第一次保存\n"), 0600)`。**WriteFile 会创建缺失文件，也会截断并覆盖已有文件**；只在自己的练习目录、新文件名上实验，先检查错误再宣布保存成功。0600 是类 Unix 的文件权限位，表示仅所有者读写；Windows 不完全按这组 Unix 权限解释。

追加用 `os.OpenFile(path, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0600)`，成功后再写入并关闭。这里的竖线是按位或，组合创建、只写、追加三个选项。WriteString 与 Close 都可能失败；缓冲写入还要检查 Flush。读取用 os.Open 时同理先检查打开错误，再登记关闭。

`filepath.Join("data", "notes.txt")` 按系统规则组合路径，`os.MkdirAll("data", 0700)` 创建缺失目录。文件写入不会自动创建上层目录。`os.Stat` 可取得大小和目录属性；判断不存在用 errors.Is(err, os.ErrNotExist)，不要按系统错误字符串猜测。

ReadFile 一次载入全部内容，适合本课小文件；大文件用 Open 配合 Scanner、Reader 或 io.Copy 分段处理。文件刚读成功也可能在稍后被外部修改，不能把一次检查当永久保证。

### 就地练习：写入前先核对目标

仅在新建的临时练习文件夹中写入一份新文件，再用ReadFile核对。若改为不存在的父目录，应该在哪一步报告失败？

### 参考核对：写入前先核对目标

WriteFile不自动创建父目录，应检查其error；失败时不能显示保存成功。不要拿真实笔记做覆盖实验。

## 先运行一个小例子

先在运行目录新建message.txt，完整内容为：

```text
今天写一点代码。
```

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	// 相对路径从终端当前目录寻找文件，ReadFile 一次读取全部字节。
	data, err := os.ReadFile("message.txt")
	if err != nil {
		fmt.Println("读取失败：", err)
		return // 缺少文件时，不能再把 data 当成成功读取的内容。
	}
	fmt.Print(string(data)) // 转换为文字；Print 不额外添加换行。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
今天写一点代码。
```

## 逐步读懂这个例子

message.txt放在运行目录。ReadFile取得字节切片，string转换后可显示。它内部完成打开与关闭；手动os.Open需要成功后安排Close。

第一步按相对路径找到文件，第二步读取字节，第三步检查 err，第四步转换和打印。任何一步读取失败，函数直接返回，不执行最后打印。

文件已经存在但内容为空：读取成功，err 为 nil，data 长度为 0。文件不存在：读取失败，err 非 nil。**空文件和缺文件是两种结果，不能用“没打印文字”来混为一谈。**

## 自己改一处再运行

暂时将文件名改成missing.txt，看错误，再恢复原名。

### 参考答案

将原程序的读取行改为 `data, err := os.ReadFile("missing.txt")`，在确认该练习目录没有同名文件后运行。输出应包含“读取失败”和 missing.txt 路径；系统具体原因文字可不同。恢复为 message.txt 后，应重新显示“今天写一点代码。”。

不要为了得到同样的错误直接删除真实笔记。本题只改变独立练习的读取路径，原 message.txt 保留。

## 写了文件却找不到时

先用 os.Getwd 查看当前工作目录，再检查相对路径。写入新位置失败还可能是父目录缺失或权限不足；把错误丢掉后再打印“保存成功”会制造假结果。打印完整失败原因并确认目标路径，避免在另一个目录重复创建同名文件。

### 就地练习：当前目录是证据

在程序开头打印os.Getwd的结果，核对相对路径。解释为什么只切换编辑器标签页不会改变它。

### 参考核对：当前目录是证据

工作目录由启动进程的位置决定；标签页只决定正在编辑哪个文件，不决定ReadFile的路径基准。

## 用三个文件状态验收

| 文件状态 | 应观察到什么 |
| --- | --- |
| message.txt 有示例文字 | 正常显示文字 |
| message.txt 存在但为空 | 没有内容输出，读取没有报错 |
| 源码改为 missing.txt，目录内没有该文件 | 打印读取失败和路径信息 |

先备份或记住文字，依次试完，再恢复 message.txt 内容和源码路径。不同系统的错误文字会不同，核对失败类别与实际路径即可，不要硬背某句系统错误。ReadFile 适合本课小文件，不是无限大文件处理方案。

## 合上参考，独立读取自己的笔记文件

在自己的独立目录新建UTF-8的notes.txt，写入“我记录了一个问题。”。从空白main.go独立读取这个文件：读失败时输出“读取失败”及实际错误并停止；成功但字节数为0时显示“文件为空”；成功且非空时先显示“读取成功”，再显示原内容。

先写预期，再在同一个终端工作目录验收三种状态：有上述文字时能显示成功及内容；清空notes.txt但保留文件时只显示空文件提示；临时改名使notes.txt缺失时显示读取失败与原路径。记录当前目录、使用的相对路径和三次结果，最后恢复文件名与内容。

**这是自行创建的新程序和文件，不是在message.txt例子里换一个文件名。** 不把缺文件读取到的占位字节当成成功空文件。

### 参考答案

先在本节独立模块目录准备 notes.txt，再运行本答案。有文字时先显示“读取成功”，后显示原内容；文件存在但0字节时只显示“文件为空”；临时改名后只显示“读取失败”及原路径。err 检查位于 len 检查之前，缺文件不会被误判为空文件。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import (
    "fmt"
    "os"
)

func main() {
	data, err := os.ReadFile("notes.txt")
	if err != nil { fmt.Println("读取失败：", err); return }
	if len(data) == 0 { fmt.Println("文件为空"); return }
	fmt.Println("读取成功")
	fmt.Print(string(data))
}
```
