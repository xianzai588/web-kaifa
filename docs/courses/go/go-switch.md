# switch 多分支选择

按一个值选择明确的分支，处理没有匹配的情况。

## 一组离散值用 case 列清楚

`if` 常判断数值范围，`switch day` 可以按一个具体值选择规则。每个 case 后面写一个或多个可匹配的值，冒号后是匹配时的语句。**普通 case 执行后就结束这个 switch，不会自动接着执行下一个 case。**

`default` 的意思只是“没有任何 case 匹配”，不等于“输入已经合法”。本例有意用最少的分支演示选择；它把所有非周末文字都归入工作日，不能当作严谨的日期校验。

### 就地练习：default不是校验

把最小示例的day改为未知，预测输出。独立列出必须增加的工作日case，才能把default留给非法输入。

### 参考核对：default不是校验

原版输出工作日；要显式列出周一到周五，default才可以报告未知星期。

## 无表达式 switch 与显式继续

`switch` 后也可以不写值，此时相当于按 true 匹配布尔 case。下面片段放 main 中，按先后选择第一个成立条件：

```go
score := 85
switch {
case score < 0 || score > 100:
    fmt.Println("无效")
case score >= 90:
    fmt.Println("优秀")
case score >= 60:
    fmt.Println("及格")
default:
    fmt.Println("未及格")
}
```

case 里的范围不是按数值大小自动排序，仍取决于书写顺序。`fallthrough` 放在普通 case 的末尾，会直接执行下一分支的语句，**不检查下一条 case 的条件**；它不是“尝试匹配下一条”。初学业务分支通常不需要它。`break` 可提前离开 switch，普通分支末尾省略 break 并不会贯穿。

### 就地练习：第一个真条件

用85和95分别走无表达式switch，圈出第一个成立的case。再交换>=60与>=90的顺序，解释变化。

### 参考核对：第一个真条件

正确顺序85及格、95优秀；交换后95也先进入及格。普通case结束即离开switch。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	day := "周六"
	// 取 day 的值，按顺序与各个 case 列出的值比较。
	switch day {
	case "周六", "周日": // 逗号表示两种值都进入这个分支。
		fmt.Println("休息日")
	default: // 前面没有任何匹配时才执行。
		fmt.Println("工作日")
	}
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
休息日
```

## 逐步读懂这个例子

day 的值匹配第一个 case 中的周六，所以打印休息日。这个 case 列了两个可选值，用逗号分隔。换成周一会进入 default。

把执行写成三个问题：day 是什么？它有没有等于“周六”或“周日”？若都没有，default 要做什么？这三个问题足够解释当前例子，不用猜测 Go 能否理解自然语言星期。

如果不写 default，未匹配时什么也不输出，程序继续执行 switch 后的语句。switch 结束不代表整个 main 必须结束。

## 自己改一处再运行

将 day 依次改成周日、周一、未知，观察 default 的含义。

### 参考答案

原小例子中周日输出休息日，周一和未知都落入工作日；这是 default 的兜底行为。上面的完整修正版明确列出五个工作日，default 仅处理未列出的输入。把 day 逐次改成周日、周一、未知，得到休息日、工作日、未知星期。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	day := "未知"
	switch day {
	case "周六", "周日":
		fmt.Println("休息日")
	case "周一", "周二", "周三", "周四", "周五":
		fmt.Println("工作日")
	default:
		fmt.Println("未知星期")
	}
}
```

预期结果：

```output
未知星期
```

## 重复 case 会在编译时暴露

同一个 switch 中重复写相同常量 case 会报错；先检查是不是复制分支时忘了改值。分支内容相同时，用 `case "周六", "周日":` 合并。未知值应由你定义的 default 处理，不能据“有 default”推断输入已验证。

## 让规则处理未知值

保持“周六、周日”分支，新增“周一”到“周五”的 case，最后把 default 改为输出“未知星期”。依次试周日、周一、未知，预期是休息日、工作日、未知星期。

若 case 少写引号，会把名字当成变量而产生编译错误。恢复字符串写法，再核对三条输入，不能只测试周六一种。

参考：[Go 语言规范](https://go.dev/ref/spec)。
