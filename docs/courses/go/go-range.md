# range 遍历切片

读取每一项的位置和值，计算总分。

## 每轮拿到的是“位置和值”

`for index, score := range scores` 每轮取出一个位置及该位置的值，顺序是下标从 0 到最后一项。**切片上第一个结果是下标，第二个结果才是元素值。**

只需要值时写 `for _, score := range scores`。下划线 `_` 表示这里有一个结果，但不用给它保存名字；它不是一个以后能读取的普通变量。只写 `for index := range scores` 则只取得下标，不能把 index 当成成绩加进总分。

### 就地练习：只接第一个结果

用[60 80 100]分别累计range的下标和分数，输出两个总和。

### 参考核对：只接第一个结果

下标和为3，分数和为240；第一个结果是位置。

## 遍历时修改数据与版本规则

range 切片时用于决定轮数的长度在开始时就确定；循环中 append 新项，不会让这个 range 自动访问新加项目。若确实需要动态队列，应另写能控制终点的循环，不把它混进第一次求和实验。

遍历数组或切片时，range 得到的元素值是副本；元素若含指针等引用关系，修改所指向对象仍可能影响原数据。Go 1.22 起，用 `:=` 声明的循环变量每轮有自己的变量；使用 `=` 赋给预先存在的变量则仍是同一变量反复赋值。第一次学习时先读下标和值，后续闭包和并发再检验捕获规则。

### 就地练习：追加会增加本轮次数吗

从[1 2]开始，每轮打印元素并追加9，循环结束打印长度。预测循环次数，避免把append换成无限条件循环。

### 参考核对：追加会增加本轮次数吗

仍只循环2次，输出1、2；最终长度4，range开始时确定本次长度。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	scores := []int{60, 80, 100}
	total := 0
	// 每轮依次取到一项：index 是下标，score 是该项的整数值。
	for index, score := range scores {
		fmt.Println(index, score)
		total += score // 把本轮分数加进循环外的总分变量。
	}
	fmt.Println("总分", total) // 全部元素处理完后再输出总分。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
0 60
1 80
2 100
总分 240
```

## 逐步读懂这个例子

每轮取得一对值：0与60、1与80、2与100。total累计三次得到240。修改原集合要写scores[index]，只写score=...不会改到原数据。

三轮的数据流依次是 `(0,60) → total=60`、`(1,80) → total=140`、`(2,100) → total=240`。总分变量在外面，循环内只更新它。

本例 score 是整数元素的一份值。循环里写 `score = 0` 只改变这一轮的局部变量；写 `scores[index] = 0` 才修改原切片中的那一项。**遍历读到一个值，并不等于已经拿到原元素的可写位置。**

## 自己改一处再运行

用空切片和只有一个分数的切片验证总分。

### 参考答案

只有一项时循环一次；初值改成 []int{} 时循环零次，只剩“总分 0”。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	scores := []int{80}
	total := 0
	for index, score := range scores {
		fmt.Println(index, score)
		total += score
	}
	fmt.Println("总分", total)
}
```

预期结果：

```output
0 80
总分 80
```

## 发现总分变成3时检查哪个名字

成绩 [60 80 100] 的下标是0、1、2，若把第一个 range 结果加起来会得到3。把变量明确命名为 index、score，并在调试时同时打印它们，能直接查出用了错误结果；别通过把初值改成别的数来补偿。

## 检验次数和原数据

输入 `[]int{}` 时没有一轮，最后只输出“总分 0”；输入 `[]int{80}` 时先输出“0 80”，最后输出“总分 80”。先预测完整行数再运行。

再在循环内将 score 改成 0，并在循环后打印 scores，确认原分数保留；改用 `scores[index] = 0` 后原数据才全为 0。一次只试一种，最后恢复参考程序。

## 合上参考，独立统计及格人数

从空白 main.go 用整数切片保存成绩，统计至少60分的人数。自己决定 range 接收哪些结果，用条件与循环外变量累计人数，只输出最终人数，不继续套用“总分”任务。

先手算再运行：59、60、100三项应为2人；空成绩应为0人；只有59应为0人；只有60应为1人。**计数依据是分数，不能把下标0、1、2当成分数去比较。**

### 参考答案

计数按 score 而不是下标判定。改成空切片、[59]、[60]，预期依次为0、0、1；total 或 passed 必须在循环外初始化。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	scores := []int{59, 60, 100}
	passed := 0
	for _, score := range scores {
		if score >= 60 { passed++ }
	}
	fmt.Println(passed)
}
```

预期结果：

```output
2
```
