# if 与 else 条件语句

根据分数选择执行哪一个分支。

## 先判断，再选一段代码执行

顺序执行是从上往下走；条件分支是在某个位置选择一条路。**if 后面必须得到 true 或 false；同一次 if/else 只执行匹配的一边。** 本课判断“是否至少 60 分”，它与“分数是否在合法范围内”是两个不同的问题。

当要分成更多范围时可以接 `else if`。例如先判断 `score < 0 || score > 100` 是否非法，再判断 `score >= 60` 是否及格，最后处理未及格。程序按顺序检查，匹配后不会继续执行后面的分支。这里的 `||` 已在运算符课解释。

### 就地练习：分支之后还会继续

在原 if/else 后加一句 `fmt.Println("检查结束")`，分别用59、60运行。先写两次的完整输出顺序。

### 参考核对：分支之后还会继续

分别先显示未及格或及格，再显示检查结束；只执行一个分支，但分支后仍继续。

## 条件的组合与分支顺序

`0 <= score <= 100` 不能在 Go 中表达范围。先分别比较，再用逻辑与连接：`score >= 0 && score <= 100`。合法范围以外则是 `score < 0 || score > 100`。

else-if 链从前往后检查，遇到一个 true 就执行并跳过余下分支。因此应先排除非法分数，再判断 90 分以上、60 分以上等范围；若先写 score >= 60，95 也会进入这条分支，后面的优秀分支永远得不到 95。

if 也可带一条初始化语句，如 `if score := 75; score >= 60 { ... }`。这个 score 的范围包含对应 else 分支，但不延伸到 if 后面。先用普通写法掌握控制流，再在 [作用域课](go-scope.md) 核对这种局部名字。

### 就地练习：优秀分支放在哪里

用95分比较“先 >=60，再 >=90”和相反次序。每次只输出一个等级，说明哪个顺序能到优秀分支。

### 参考核对：优秀分支放在哪里

先>=60会提前匹配及格；先排除非法值，再>=90、>=60，95才能显示优秀。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	score := 60
	// 先计算比较结果；只有为 true 时才进入这对花括号。
	if score >= 60 {
		fmt.Println("及格")
	} else {
		// 同一次判断不满足条件时，执行另一边。
		fmt.Println("未及格")
	}
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
及格
```

## 逐步读懂这个例子

score 是 60，60>=60 为 true，所以只打印及格。分支里的语句在条件成立时才会执行。Go 的条件不必额外套一层圆括号，但分支花括号必须保留；else 通常与前一个 } 写在同一行。

| score | `score >= 60` | 进入哪里 | 输出 |
| --- | --- | --- | --- |
| 59 | false | else 的花括号 | 未及格 |
| 60 | true | if 的花括号 | 及格 |
| 100 | true | if 的花括号 | 及格 |

花括号内部的缩进表示这一分支包含哪些语句；**决定范围的是配对花括号，不能只靠缩进猜测。** 分支结束后，函数仍会继续执行 if/else 后面的语句。

## 自己改一处再运行

用 59、60、100 分别运行，并记录三个结果。

### 参考答案

把后面的范围校验也合并进完整答案。先检查非法值，避免 -1 被当作未及格、120 被当作及格。逐次将 score 改成 -1、59、60、100、120，预期为分数无效、未及格、及格、及格、分数无效。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	score := 60
	if score < 0 || score > 100 {
		fmt.Println("分数无效")
	} else if score >= 60 {
		fmt.Println("及格")
	} else {
		fmt.Println("未及格")
	}
}
```

预期结果：

```output
及格
```

## 用反例查出范围判断错误

若写成 `score >= 0 || score <= 100`，任意整数至少满足其中一边，非法的 120 也通过。先把 120 和 -1 代入每个子条件，写出 true/false，再决定连接符。范围内要“两边都成立”用 &&；范围外要“任一越界”用 ||。

## 检查未覆盖的输入

先运行 -1 和 120。原程序会分别显示未及格与及格，说明它没有检验 0–100 的范围。再亲手在最前面加非法范围分支，让两种值都输出“分数无效”，并确认 59、60、100 仍正确。

把条件写成 `if score {` 会报错，因为 score 是整数，不是布尔值。恢复明确的比较条件后再运行。
