# 字符串的字节与 rune

观察中文字符串的字节数、Unicode码点数和遍历位置。

## 同一段文字可以有两种计数

字节是计算机存储数据的单位；Unicode 给字符分配数字编号，这个编号叫码点。UTF-8 是把码点编码成字节的方式，英文 G 常占一个字节，汉字“中”占三个字节。

**len(字符串) 返回字节数；len([]rune(字符串)) 返回解码后的码点数。** `rune` 是 `int32` 的别名，用于表示码点；int32 是固定使用 32 位保存的整数类型，本课只需知道它能保存这些编号。`[]rune(text)` 明确转换成一个码点切片，并没有修改原字符串。

单引号的 `'中'` 是一个 rune 值，双引号的 `"中"` 是字符串；`'中文'` 不能当作一个 rune。多码点组合成一个视觉字符的情况也存在，所以码点数仍不等于所有场景下的“用户看到几字”。

### 就地练习：位置按哪种单位

把text设为“中A文”，先写len、rune数量以及range的三个index，再运行。

### 参考核对：位置按哪种单位

字节7、码点3；index是0、3、4，为码点在UTF-8中的起始字节位置。

## 无效 UTF-8 与用户可见字符

Go 的 string 可以含任意字节，不保证内容一定是合法 UTF-8。`unicode/utf8.ValidString(text)` 可验证；range 遇到无效编码会返回替换码点 U+FFFD，并向前消费一个字节。转换成 []rune 后再变回 string 可能已替换原始坏字节，不能当成无损二进制复制。

`e` 加组合重音与单个预组合字母，视觉上可能相似，码点数却不同；家庭 emoji 也可能由多个码点组成。限制字节数可约束传输大小，限制码点数可粗略约束文本长度，要限制用户看到的字符则需要额外的字素分段规则。不要把三种单位都写成含糊的“字数”。

### 就地练习：相似显示不同计数

比较“é”与用e加组合重音表示的字符串，分别打印字节数和rune数。不要仅凭肉眼判相等。

### 参考核对：相似显示不同计数

预组合é为2字节1码点，e加组合重音为3字节2码点；视觉相似不代表相同字节或码点序列。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	text := "Go中"
	// len(text) 数字节；转换成 []rune 后，len 数 Unicode 码点。
	fmt.Println(len(text), len([]rune(text)))
	// index 是码点起始位置的字节下标，r 是这一个码点的值。
	for index, r := range text {
		fmt.Printf("%d %c\n", index, r) // %c 将码点显示成对应字符。
	}
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
5 3
0 G
1 o
2 中
```

## 逐步读懂这个例子

G和o各占一个UTF-8字节，中占三个，共5字节。解码后有3个码点。range在字符串上给出码点起始字节下标与码点值，%c按字符显示。不要按字节下标随便截断中文。

| 文字片段 | UTF-8 字节数 | 起始字节下标 |
| --- | --- | --- |
| G | 1 | 0 |
| o | 1 | 1 |
| 中 | 3 | 2 |

三段合计 5 字节，但只有 3 个码点。range 返回的第一个数是该码点在原字符串中的**起始字节下标**，不是第几个汉字。`%c` 把整数码点按字符显示，`%d` 则显示这个编号的十进制数字。

## 自己改一处再运行

改成“中文”，先预测两个len的结果再运行。

### 参考答案

每个汉字占3个 UTF-8 字节，range 的位置是0、3，元素值则是完整码点。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	text := "中文"
	fmt.Println(len(text), len([]rune(text)))
	for index, r := range text { fmt.Printf("%d %c\n", index, r) }
}
```

预期结果：

```output
6 2
0 中
3 文
```

## 看见乱码时分开检查两件事

先确认文件与终端使用的编码，再检查代码是否把多字节字符截断。编码设置正确也不能修复 `text[:1]` 切坏中文的问题；正确取码点同样不能把错误来源编码自动识别成 UTF-8。

## 用中文证明字节下标的差别

改成“中文”：字节数 6、码点数 2；range 两次的位置分别为 0、3。改成空字符串，两种长度都为 0，循环不执行。

若想取第一个完整汉字，先转换成 rune 切片，判断非空，再取下标 0。直接取 text[:1] 只拿到 UTF-8 编码的一部分，可能显示损坏文字。字符串内容不可用 `text[0] = ...` 修改；要建立新的字符串。

## 合上参考，安全显示第一个码点

从空白 main.go 保存一段文字，先显示字节数与码点数，再安全输出第一个完整码点；没有首项时显示“没有首项”。自行选择转换、非空判断和字符格式，不能直接截取第一个字节。

| 文字 | 字节数、码点数 | 第二行 |
| --- | --- | --- |
| 中文 | 6、2 | 中 |
| A中 | 4、2 | A |
| 空字符串 | 0、0 | 没有首项 |

先预测再保存运行。**空输入也必须走完自己的程序，不能为躲避越界把这项验收跳过。** 本题指首个Unicode码点，不声称处理所有视觉组合字符。

### 参考答案

先转成码点切片再检查长度。text 改为 A中得到4、2及 A；改为空得到0、0及“没有首项”。text[:1] 只取一个字节，不能保证一个完整汉字。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	text := "中文"
	runes := []rune(text)
	fmt.Println(len(text), len(runes))
	if len(runes) == 0 {
		fmt.Println("没有首项")
	} else {
		fmt.Printf("%c\n", runes[0])
	}
}
```

预期结果：

```output
6 2
中
```
