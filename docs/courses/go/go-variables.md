# 变量声明与赋值

用 var 和 := 保存一个值，再用 = 修改已有变量。

## 声明、赋值、读取是三个动作

**变量是一个有名字、能保存某类值的位置；打印变量会读它当前的值。** “声明”创建名字，“赋值”存入或更新值，“读取”取得已经保存的值。

| 写法 | 发生的动作 |
| --- | --- |
| `var score int = 80` | 声明一个整数变量，初值为 80 |
| `var score = 80` | 声明变量，由初值推断为整数 |
| `score := 80` | 在函数内简写声明，并提供初值 |
| `score = 90` | 给已经存在的 score 重新赋值 |
| `fmt.Println(score)` | 读取当前分数并输出 |

上面前三行是声明的不同写法，练习时**选其中一种**，不要放在同一个范围内重复声明三遍。同一个变量可以多次赋值。类型会在下一课详细解释。

### 参考核对：没有打印的更新

## 一次声明多个名字与赋值次序

以下片段都放在 main 内，按顺序运行：

```go
a, b := 10, 20
a, b = b, a // 先取得右边两个旧值，再分别写到左边。
fmt.Println(a, b) // 20 10
```

多重赋值要求左右数量对应。`a, c := 30, 40` 在同一作用域是合法的：c 是新名字，a 接收新值；仅写 `a := 30` 却没有新名字就不合法。`:=` 只能出现在函数内，包级声明用 var。局部变量声明后不使用会报错，拼错名字则可能报未定义。

`n := 1` 先决定 n 是 int，以后给 n 赋值仍须满足这个类型；`n = 1.5` 不会把它自动改成 float64。需要小数就从一开始用适当类型声明，下一课学习类型与转换。

### 就地练习：同时交换和逐项覆盖

让 a、b 初值为 10、20，对比 `a,b=b,a` 和从同样初值开始的 `a=b; b=a`。分别在纸上跟踪旧值，再运行。

### 参考核对：同时交换和逐项覆盖

同时赋值后为 20、10；逐项赋值后为 20、20，第二句已读到更新的 a。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	// := 第一次声明 score，并把整数 80 作为初值。
	score := 80
	fmt.Println(score) // 不加引号：读取变量当前保存的值。
	// = 更新已有变量；这一步没有创建第二个 score。
	score = 90
	fmt.Println(score) // 前面的赋值已执行，因此这里读到 90。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
80
90
```

## 逐步读懂这个例子

第一行创建 score 并放入 80。第一次打印读取当前值 80。`score = 90` 把值更新为 90，第二次打印读到的是更新后的值。变量名没有引号；`"score"` 打印的是这个单词本身。

可以把执行前后写成小表：

| 已执行到哪一步 | score 当前值 | 终端新增内容 |
| --- | --- | --- |
| 声明并赋初值 | 80 | 没有 |
| 第一次打印 | 80 | 80 |
| 更新赋值 | 90 | 没有 |
| 第二次打印 | 90 | 90 |

**赋值不会自动输出，打印不会自动修改分数。** 同样，更新变量不会把终端已经打印的 80 改成 90。

## 自己改一处再运行

把初值改成 60，更新值改成 75，先写下两行预期再运行。

### 参考答案

声明只发生一次。第二次用 = 写入新值，再读取当前值。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	var score int = 60
	fmt.Println(score)
	score = 75
	fmt.Println(score)
}
```

预期结果：

```output
60
75
```

## 同名声明错误怎样修复

`no new variables on left side of :=` 表示这一层范围里没有新名字。如果目的是更新值，改用 `=`；如果确实要表示另一项数据，给它一个能说明含义的新名字。不要为消除错误随意再套花括号，那会创建另一层变量，后面读到的可能仍是旧值。

未使用变量的报错要检查调用是否拼错名字，或这项数据是否真的需要。`_ = value` 可明确丢弃值，但本课练习要输出数据，不应借此掩盖漏写的打印。

## 试一次声明错误，再恢复

把第二次赋值 `score = 90` 改成 `score := 90`。同一个范围没有新变量可声明，运行应报错，且不会产生本课的正常输出。恢复 `=` 后重新运行。

再把第一次输出改为 `fmt.Println("score")`：它应输出文字 `score`；改回 `fmt.Println(score)` 才会读取 80。解释这两次差别，比背住符号更重要。

## 合上参考，独立表示一次数据变化

从空白 main.go 表示“今天计划练习的分钟数”：最初为 10，后来调整为 25。自己为这项数据命名，选择本节的一种声明写法，在更新前后各打印一次；更新时使用已有变量，不再创建同名变量。

先预测两行，保存运行，应依次为 10、25。再将调整值设为 0，预期是 10、0。**说明哪一步声明、哪一步赋值、哪一步读取，不能把“改过值”当作已经输出。**

### 参考答案

minutes 先保存 10，赋值后变成 25。把第二次赋值改成 minutes = 0，再运行应是 10、0；第一次输出不会随之后的赋值倒回去变化。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	minutes := 10
	fmt.Println(minutes)
	minutes = 25
	fmt.Println(minutes)
}
```

预期结果：

```output
10
25
```
