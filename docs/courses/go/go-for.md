# for 循环与累加

跟踪循环变量，计算 1 到 5 的和。

## 循环每一轮到底做什么

**循环不是一次把所有数相加，而是反复执行同一段代码，每一轮更新状态。** `for` 后面的三段由分号分隔：初始化只做一次，条件每轮前检查，更新在每轮主体结束后执行。

| 本例中的部分 | 作用 |
| --- | --- |
| `i := 1` | 给计数变量初值 1，只执行一次 |
| `i <= 5` | 为 true 才进入本轮，否则离开循环 |
| `i++` | 当前轮结束后把 i 增加 1 |
| `total += i` | 把本轮 i 加到已有总和里 |

`i++` 相当于 `i = i + 1`，`i--` 则减少 1。Go 也能只写条件，例如 `for total < 10 { ... }`；主体必须有使条件改变的操作，否则可能永远不停。

## 三种写法，以及 continue 后从哪里继续

| 写法 | 使用场景 | 结束方式 |
| --- | --- | --- |
| `for i := 0; i < 3; i++ { ... }` | 知道计数规则 | 条件变 false 或 break |
| `for remaining > 0 { ... }` | 按状态重复 | 主体需要更新 remaining |
| `for { ... }` | 持续服务或等待事件 | 用 break、return 或取消机制明确退出 |

三段式 for 中的 continue 会跳到更新语句，再检查条件；只有条件的 for 若把更新写在主体末尾，continue 可能跳过它，形成死循环。break 只结束最内层的循环；return 则结束整个函数，下一课开始练函数。

Go 1.22 起可写 `for i := range 3` 遍历 0、1、2，但先用本课三段式看清初始化和终点，range 课再学习集合遍历。循环变量的作用范围限于这个循环块，循环外不要直接读取初始化里声明的 i。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	total := 0 // 保存已经加过的数之和；必须放在循环外。
	// 从 1 开始；每轮前检查 i<=5；每轮结束后让 i 增加 1。
	for i := 1; i <= 5; i++ {
		total += i // 等同 total = total + i，保留前面各轮的结果。
	}
	fmt.Println(total) // 循环全部结束后，只打印一次总和。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
15
```

## 逐步读懂这个例子

total 从 0 开始。五轮里 i 分别为 1、2、3、4、5，total 依次为 1、3、6、10、15。i 变成 6 时条件为 false，退出循环，再打印结果。`total += i` 等价于 total = total + i。

| 轮次 | 主体开始时的 i | 加之前 total | 加之后 total |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

第五轮结束后 i 变成 6，下一次条件不成立，才执行末尾的 Println。如果把 total 的声明放到循环里面，每轮都会重新从 0 开始，无法累计前面结果。

## 自己改一处再运行

把 <=5 改成 <=3，再把上限改成 0，预测各自结果。

### 参考答案

三轮分别加 1、2、3，得到 6。将条件改成 i <= 0，第一轮就不进入，total 保持初值 0。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	total := 0
	for i := 1; i <= 3; i++ {
		total += i
	}
	fmt.Println(total)
}
```

预期结果：

```output
6
```

## 提前结束与跳过一轮

循环里的 `break` 结束当前循环，`continue` 跳过这一轮主体剩下的语句，进入下一轮。在原循环体最前面加 `if i == 3 { break }`，总和应为 3；改成 `if i == 3 { continue }`，只跳过数字 3，总和应为 12。一次只加其中一种，并实际验证后删去。

再把上限改成 0，程序应直接输出 0。不要用没有更新计数的无限循环测试；若真的持续运行，用终端 `Ctrl+C` 停止，修复循环条件再启动。

## 合上参考，独立求偶数之和

从空白 main.go 计算 1 到给定上限之间的偶数之和，上限保存在整数变量中。只用已学 for、if、余数和输出，自行安排计数起点、继续条件、每轮更新与循环外的累计值。

上限为6时结果应为12，为5时应为6，为0时应为0。先列出上限6时前三轮的“当前数、是否偶数、累计值”，再运行核对最终结果。**不得直接打印12，也不要让累计变量每轮重新从0开始。**

### 参考答案

i 为 1、2、3 时，是否偶数依次为 false、true、false，累计值为 0、2、2。到 6 时加过 2、4、6，总计 12；把 limit 改为 5 得到 6，为 0 得到 0。累计值放在循环外，才能保存前一轮的结果。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	limit := 6
	total := 0
	for i := 1; i <= limit; i++ {
		if i % 2 == 0 {
			total += i
		}
	}
	fmt.Println(total)
}
```

预期结果：

```output
12
```
