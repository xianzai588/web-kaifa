# 字符串与终端输出

连接字符串，区分打印文字与打印变量。

## 文字、变量名与格式占位符

**字符串保存文字；变量名是代码里的名字，两者不能因为看起来相似就互换。** `name` 读取变量，`"name"` 是四个字母组成的文字。

| 写法 | 作用 |
| --- | --- |
| `"你好，" + name` | 连接两段字符串 |
| `fmt.Println("你好，", name)` | 打印两个值，中间有空格，末尾换行 |
| `fmt.Print("你好")` | 打印后不额外换行 |
| `fmt.Printf("%d 分钟\n", 20)` | 按格式插入整数，再换行 |

双引号字符串里，`\n` 是换行、`\t` 是制表符、`\"` 是一个文字双引号、`\\` 是一个反斜杠。反引号包住的字符串保留内容原样，例如 `` `a\nb` `` 包含反斜杠和字母 n，不会在这个位置换行；后面写 JSON 输入时会用到它。

### 就地练习：变量名还是文字

声明 `name := "阿青"`，分别打印 name 与 "name"。接着用 Print 连续输出 A、B，用 Println 结束这一行。

### 参考核对：变量名还是文字

前两次分别显示阿青、name。Print 不自动换行，连续内容会相接；代码名字不会自动变成同名文字。

## 字符串字面量与三种输出方式

双引号字符串解释转义，反引号字符串保留换行与反斜杠。两者产生的都是 string，选哪种取决于要保存的内容，而不是有两种文字类型。

```go
fmt.Printf("%q\n", "第一行\n第二行") // 输出带转义的可辨认形式。
fmt.Println(`C:\notes\go`) // 反引号内的反斜杠原样保留。
```

字符串是不可变的字节序列。`text = text + "!"` 是把连接结果重新赋给变量，不是修改原文字内部的一项。长度和中文字符计数在 [字节与 rune](go-unicode.md) 详细实验。

Print 只输出值，Println 在值之间加空格并在最后换行，Printf 按格式输出且不自动换行。要生成字符串供后续保存或比较，用 `fmt.Sprintf("今天 %d 分钟", minutes)`；Sprintf 返回文字而不打印。先在终端练清这四者，再把字符串用于文件或 HTTP。

### 就地练习：保留反斜杠

分别用双引号和反引号表示 a、反斜杠n、b，使用 %q 显示。说清哪个包含真正换行、哪个保留两个字符。

### 参考核对：保留反斜杠

双引号中的转义序列产生换行，%q 将它显示为 \n；反引号保留反斜杠和n，%q 会转义反斜杠。

## 输出不止 Println：格式、返回字符串与目标位置

| 工具 | 自动换行吗 | 结果去哪里 |
| --- | --- | --- |
| `fmt.Print(a, b)` | 否 | 标准输出；空格规则不应代替显式格式 |
| `fmt.Println(a, b)` | 是 | 标准输出，参数之间加空格 |
| `fmt.Printf(格式, 参数...)` | 否 | 标准输出，完全按格式安排 |
| `fmt.Sprint`、`fmt.Sprintf` | 否 | 返回字符串，不直接显示 |
| `fmt.Fprint`、`fmt.Fprintf`、`fmt.Fprintln` | 由所选函数决定 | 第一个参数指定写入目标，例如标准错误或文件 |

常用格式符按实际参数类型选择：

| 格式 | 示例和用途 |
| --- | --- |
| `%v` | 通用值显示；调试时先看值 |
| `%T` | 显示类型，例如 int、string |
| `%d`、`%b`、`%x` | 整数的十进制、二进制、十六进制 |
| `%f`、`%.2f`、`%e` | 浮点默认小数、两位小数、科学计数法 |
| `%s`、`%q` | 直接显示字符串、带引号和转义显示字符串 |
| `%c`、`%U` | 按字符或 Unicode 编号显示整数码点 |
| `%t` | 显示 true/false |
| `%%` | 显示一个百分号，不消耗参数 |
| `%6d`、`%06d`、`%-6s` | 最小宽度6、用0补齐整数、字符串左对齐；宽度不是截断上限 |

下面是可单独运行的完整 main.go，演示如何分辨空格、换行与返回的字符串：

```go
package main

import "fmt"

func main() {
    name := "阿青"
    minutes := 30
    fmt.Print("开始")
    fmt.Println("练习", name)
    fmt.Printf("分钟=%03d，小时=%.2f，完成=%t，进度=50%%\n", minutes, float64(minutes)/60, false)
    report := fmt.Sprintf("%s 练习 %d 分钟", name, minutes)
    fmt.Printf("类型=%T，文字=%q\n", report, report)
}
```

预期：

```output
开始练习 阿青
分钟=030，小时=0.50，完成=false，进度=50%
类型=string，文字="阿青 练习 30 分钟"
```

第一条 Print 不换行，因此后面的 Println 紧接“开始”；Sprintf 不产生一行输出，直到下一条 Printf 才显示 report。`%.2f` 仅控制显示的小数位，不会把内部数值改成精确的两位小数。

需要将错误信息与正常结果分开时，在 main.go 的 import 中加入 os，并在 main 内写 `fmt.Fprintln(os.Stderr, "输入无效")`。普通 Println 仍写标准输出。学完错误处理后还应检查写入调用返回的错误，例如下游文件或管道关闭；不能仅因调用了打印函数就认定数据已成功保存。

macOS/Linux 和 cmd 可用 `go run . > result.txt 2> errors.txt` 分别保存标准输出和标准错误。重定向后终端看不到原来的正常输出，要去 result.txt 检查；PowerShell 的文本编码行为取决于版本，按自己的终端文档核对，不把它当作二进制转发工具。

### 就地练习：返回字符串不等于打印

在完整格式化示例中，暂时删除最后一条 Printf，保留 report 的赋值；为避免未使用，用 `_ = report`。预测哪些输出消失，再恢复。

### 参考核对：返回字符串不等于打印

类型与文字那一行消失；Sprintf只返回文字，不产生终端输出。恢复最后一条Printf后才能看见report。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	name := "小林" // 引号包住文字；name 是保存这段文字的变量。
	// + 把两段字符串连接，最终输出不包含源码中的引号或加号。
	fmt.Println("你好，" + name)
	// %d 由后面的整数 20 替换；\n 让输出另起一行。
	fmt.Printf("今天练习 %d 分钟\n", 20)
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
你好，小林
今天练习 20 分钟
```

## 逐步读懂这个例子

name 保存称呼。加号把固定文字与变量的内容连接起来。Printf 的 %d 是整数位置，后面的 20 填入这个位置，\n 表示换行。代码中的 +、引号和格式符不是最终输出的一部分。

第一行先读到 name 保存的“小林”，再把固定问候与它拼成“你好，小林”。第二行不是字符串加法：Printf 在 `%d` 的位置显示整数 20，并解释 `\n` 为换行。

格式中的 `%s` 可插入字符串，`%d` 可插入整数；占位符按后续参数的先后顺序对应。这里只输出文本，没有从终端读取输入。

## 自己改一处再运行

### 参考答案

称呼按题意可换成自己的名字。分钟数仍是整数，由 %d 格式化进句子。

预期结果：

```output

```

## 格式不匹配的现象

`fmt.Printf("%d", "30")` 不会把文字转换成整数，运行时会出现 `%!d(string=30)` 一类格式诊断。核对占位符和参数类型；需要文字用 %s，需要整数用 %d。漏写末尾的 `
` 则会让下一条输出紧接着出现。

### 就地练习：格式符不会解析输入

在 main 比较 `fmt.Printf("%s\n", "30")` 和 `fmt.Printf("%d\n", "30")` 的结果。只做观察，不把格式诊断当作输入转换。

### 参考核对：格式符不会解析输入

前者显示30；后者给出%!d(string=30)一类诊断。打印格式不会把字符串解析为整数。

## 做两组可区分的实验

先打印 `"name"` 与 name，预期分别看到 name 与小林。再把第一条输出的 `Println` 改成 `Print`，第二条保持原样，观察两句会连在同一行；恢复 Println 后重新核对。

直接写 `"练习" + 20` 会产生类型错误。要插入分钟数，使用已讲的 `Printf`，而不是给数字乱加引号后继续做加减。
