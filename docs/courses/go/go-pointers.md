# 指针与修改调用者变量

用&取得地址，用*访问地址指向的整数。

## 交一份数字，还是交数字所在的位置

前面的 Change(n int) 得到整数副本，改 n 不改调用者。现在交出原变量的位置，让函数明确访问那里。**指针保存地址；通过指针写入目标值，会改变这个地址处的原变量。**

| 写法 | 这里是什么意思 |
| --- | --- |
| `value` | 原整数变量保存的 3 |
| `&value` | 取得这个变量的地址 |
| `p *int` | 参数 p 是“指向整数的指针”类型 |
| `*p` | 访问 p 指向的那个整数 |
| `*p = 9` | 向这个位置写入 9 |

`*` 出现在类型中与出现在表达式中用途不同；在两个数字之间时它还是乘法。先按所在位置判断含义，不把所有星号读成同一件事。

### 就地练习：地址与目标分开读

令n:=3，p:=&n，先打印*p，再写*p=4并打印n。指出哪一步复制地址、哪一步更新整数。

### 参考核对：地址与目标分开读

先3后4；p:=&n保存地址，*p=4通过地址写回原整数。

## 改指针目标与改局部指针

`*p = 9` 写入目标整数，`p = &other` 只是让局部参数指向另一变量，不会改变调用者手里的指针。若返回函数内局部变量的地址，Go 会保证被引用的变量仍有合适生命周期，不要求手工 free；但这不意味着任意地址都有效。

`new(int)` 创建一个零值整数并返回 *int，使用时仍通过 *p 读写。结构体指针的字段可用 p.Field 直接访问，不必每次写 (*p).Field。nil 指针表示没有目标，是否允许 nil 应在函数约定中说明；本课 Increment 要求传真实变量地址。

### 就地练习：换局部指针不换外部目标

在Change中将*p=9替换成 `other:=9; p=&other`，main仍传&value。预测main最后的value。

### 参考核对：换局部指针不换外部目标

仍为3；只重定向了局部参数p，没有写入原地址处的整数。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

// p 的类型是 *int，它保存一个整数变量的地址。
func Change(p *int) {
	*p = 9 // *p 表示地址处的整数；赋值会写入调用者的那个变量。
}

func main() {
	value := 3
	Change(&value)     // & 取得 value 的地址，将该地址交给 Change。
	fmt.Println(value) // 函数已经通过这个地址把 value 改为 9。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
9
```

## 逐步读懂这个例子

main把value的地址传给Change。参数p保存地址，*p=9明确写入目标整数，所以main的value变成9。指针本身仍按值传递，复制的是地址。

调用前 value 为 3。调用时，&value 的地址值复制给 p，p 仍是本次调用的局部参数；不过这个地址指向的是 main 的原变量。写 `*p=9` 改目标整数，调用返回后 main 再读取便得到 9。

Go 的参数依然按值传递，这次复制的是地址。指针并不是“所有赋值都变成共享”，它让你选择通过哪个位置访问数据。

## 自己改一处再运行

在函数里先打印*p，再赋值9，预测两行。

### 参考答案

函数先读取地址处旧值3，再写9；main 最后读取同一原变量。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func Change(p *int) {
    fmt.Println(*p)
    *p = 9
}

func main() {
	value := 3
	Change(&value)
	fmt.Println(value)
}
```

预期结果：

```output
3
9
```

## nil 要在解引用之前检查

如果函数约定允许 nil，就在 `*p` 出现之前用 `if p == nil` 明确处理；若不允许，则调用者负责提供有效目标。返回“0”掩盖 nil 会把缺失目标与合法整数0混为一谈，不能当通用修复。

## 地址必须指向有效目标

在 Change 里写入之前打印 `*p`，预期先看到 3，再从 main 看到 9。把调用误写为 `Change(value)` 会产生类型错误，因为整数不符合 *int 参数；恢复 &value。

仅声明 `var p *int` 得到 nil 指针，也就是没有目标地址。访问 `*p` 会 panic；需要先有实际变量的地址才能解引用。当前示例通过 &value 保证有目标，不需要学习 unsafe 或手工内存管理。

## 合上参考，独立写一次递增

从空白 main.go 自己定义 Increment(p *int)，将指针目标保存的整数增加1，而不是固定写成9。main 创建一个实际整数变量，打印调用前的值，交出这个变量的地址，再打印调用后的值。

| 初值 | 调用前 | 调用后 |
| --- | --- | --- |
| 3 | 3 | 4 |
| 0 | 0 | 1 |
| -2 | -2 | -1 |

先写预期再运行三次，并解释参数复制的是哪一个地址、真正更新的是哪一个整数。**本题传实际变量的地址，不传没有目标的nil指针。**

### 参考答案

右侧 *p 取得旧值，左侧 *p 指定写回位置。初值0时得到0、1；初值-2得到-2、-1。没有固定写入9，因此结果随输入改变。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func Increment(p *int) {
    *p = *p + 1
}

func main() {
	value := 3
	fmt.Println(value)
	Increment(&value)
	fmt.Println(value)
}
```

预期结果：

```output
3
4
```
