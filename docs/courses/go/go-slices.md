# 切片与 append

用切片保存可增长的一组整数，理解长度与切片范围。

## 切片的长度可以随追加改变

**切片描述一段元素数据；append 的返回值才代表追加后的新切片。** `[]int` 没有把长度写进类型，`[]int{60,80}` 当前长度是 2。`[3]int` 的数组长度则固定在类型里。

切片范围 `scores[1:3]` 包含下标 1、2，不包含 3，所以有 `3-1=2` 项。省略起点的 `scores[:2]` 从 0 开始；省略终点的 `scores[1:]` 取到当前长度末尾。仅有 `scores[1]` 时取得一个整数，不是一个切片。

空切片 `[]int{}` 当前没有元素。`var scores []int` 的零值叫 nil 切片，也没有元素，两者都能 append；但它们都没有可以读取的下标 0。

### 就地练习：含起点不含终点

给切片[10 20 30 40]写出[1:3]、[:2]、[2:]的内容与长度，再运行核对。

### 参考核对：含起点不含终点

依次[20 30]、[10 20]、[30 40]，长度均为2；[1]只取整数20。

## make、容量、展开追加与删除

`make([]int, 2, 5)` 的长度是2、容量是5，当前能索引的只有0、1。长度小于容量时 `s = s[:3]` 可以把可见长度扩至3；但不能越过容量。切片没有固定的容量增长倍数承诺，不要把某次观察到的 cap 变化当语言规则。

追加多项可写 `s = append(s, 3, 4)`。若已有另一个切片 other，用 `s = append(s, other...)` 展开其元素。追加后仍要接回返回值。

删除位置 i 的常见写法是 `s = append(s[:i], s[i+1:]...)`，前提是 `0 <= i && i < len(s)`；它通常复用底层数组，其他共享切片也可能观察到内容变化。需要保持原集合时先独立复制，见 [下一课](go-slice-sharing.md)。

`nil` 切片与非 nil 的空切片长度都为0，但不是完全等价：后续 JSON 编码时常分别成为 null 与 []。先按业务约定选择，再用长度判断有没有元素。

### 就地练习：容量不产生现有元素

创建make([]int,2,5)，先打印len、cap与切片，再扩展为s[:3]并打印。不尝试越界写入。

### 参考核对：容量不产生现有元素

初始长度2、容量5、[0 0]；扩展后长度3、[0 0 0]，初始可索引范围只有0、1。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	scores := []int{60, 80} // []int 类型不写固定长度，当前有两项。
	// append 返回追加后的切片；赋值才能让 scores 代表新结果。
	scores = append(scores, 100)
	fmt.Println(scores, len(scores))
	// 范围包含下标 1、不包含下标 3，因此读到第二项与第三项。
	fmt.Println(scores[1:3])
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
[60 80 100] 3
[80 100]
```

## 逐步读懂这个例子

初始两项，append之后三项。scores[1:3]取下标1、2的值，所以是80、100。切片不是独立拷贝数据的承诺；下一节用修改实验看共享。

赋值执行前 scores 表示 `[60 80]`。`append(scores,100)` 计算追加结果，外面的 `scores =` 保存返回值；之后长度为 3，再取 `[1:3]` 才能看到 `[80 100]`。

切片还有容量，`cap(scores)` 表示从当前起点可使用的底层元素空间。长度以内的项才能直接索引，容量有余量也不意味着可以随意写 scores[len(scores)]。append 可能复用原空间，也可能分配新空间，具体共享由下一课实验确认。

## 自己改一处再运行

再追加90，取scores[0:2]并预测输出。

### 参考答案

先后接回两次 append 的返回值，再取含起点、不含终点的范围 [0:2]。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	scores := []int{60, 80}
	scores = append(scores, 100)
	scores = append(scores, 90)
	fmt.Println(scores)
	fmt.Println(scores[0:2])
}
```

预期结果：

```output
[60 80 100 90]
[60 80]
```

## 为什么容量够，直接赋值仍越界

对 `s := make([]int, 0, 5)` 执行 `s[0] = 1` 仍会 panic，因为长度是0。追加用 `s = append(s, 1)`，或在确实需要固定长度时创建 `make([]int, 5)`。长度决定已存在的可索引范围，容量只决定可扩展空间。

## 零项与范围实验

先将初始值改成 `[]int{}`，只保留 append 和完整切片输出，预期得到 `[100] 1`。原来的 `[1:3]` 范围不再合法，删掉或调整这个取片操作后再运行。

写成 `append(scores,100)` 而不使用返回值会被编译器拒绝。这能提醒你：**追加是一次产生新结果的调用，需要明确接住结果。**

## 合上参考，独立展示至多两项清单

从空白 main.go 管理一个字符串切片清单。先独立实现“展示当前完整清单、长度以及至多前两项”，展示范围由当前长度决定，不能一律取到下标2。

| 当前清单 | 长度 | 展示的前至多两项 |
| --- | --- | --- |
| 空清单 | 0 | [] |
| Go | 1 | [Go] |
| Go、Web | 2 | [Go Web] |

再从两项清单追加“SQL”，自行接回追加结果。完整清单应为 `[Go Web SQL]`、长度3，而展示仍为 `[Go Web]`。**零项时也要执行你写的展示逻辑，证明它不会越界。** 可直接写在 main 中，不需要尚未学习的 range 或多返回值函数。

### 参考答案

终点取当前长度与2的较小值。初值改为空清单时第一行是 [] 0 []；改成只有 Go 时为 [Go] 1 [Go]，不会越界。追加 SQL 后重新计算显示终点，才能同时适应不同初值。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	items := []string{"Go", "Web"}
	end := len(items)
	if end > 2 { end = 2 }
	fmt.Println(items, len(items), items[:end])
	items = append(items, "SQL")
	end = len(items)
	if end > 2 { end = 2 }
	fmt.Println(items, len(items), items[:end])
}
```

预期结果：

```output
[Go Web] 2 [Go Web]
[Go Web SQL] 3 [Go Web]
```
